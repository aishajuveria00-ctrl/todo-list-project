# Student To-Do List Application

A beginner-friendly student project built with HTML, CSS, and JavaScript.

## Features
- Add tasks
- Mark tasks as completed or pending
- Edit and delete tasks
- Filter all, pending, and completed tasks
- Clear completed tasks
- Save tasks in browser Local Storage
- Responsive layout for mobile and desktop

## How to run
1. Extract `Student_ToDo_List.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a modern web browser.
4. Add tasks and start using the app.

No installation or internet connection is required after the files are downloaded.

## Project structure
- `index.html` — page structure
- `style.css` — layout and styling
- `script.js` — task management and browser storage

## Technologies
HTML5, CSS3, JavaScript, Local Storage

## Important note
Tasks are saved in the same browser on the same device. Clearing browser site data may remove them.
